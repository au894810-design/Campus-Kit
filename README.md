CampusKit

A responsive landing page for a college student support platform. It includes an interactive email signup confirmation, feature sections, a dashboard preview, and mobile styling.

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server.

## Publish with GitHub Pages

1. Create a public GitHub repository.
2. Push these files to its `main` branch.
3. In the repository, open **Settings → Pages**, select **Deploy from a branch**, then choose `main` and `/ (root)`.
